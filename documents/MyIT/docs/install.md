# چگونه سیستم را راه اندازی کنیم ؟

1. نصب پایتون 
2. نصب کتابخانه  های فایل libraries  برای پایتون(پوشه برنامه >پوشه required >فایل libraries.txt)
3. نصب دیتابیس postgresql روی پورت 5002 
4. ایجاد یک دیتابیس در postgresql (در صورت نیاز بعد از ایجاد دیتابیس میتوان دیتابیس قبلی را بازآوری کرد)
5. تنظیم کردن فایل اسکریپت  Database_Backup_Script.bat و تعریف آن در task scheduler برای پشتیبان گیری روزانه از دیتابیس
6. راه اندازی فایل app.py به عنوان یک سرویس ویندوزی با استفاده از برنامه nssm 
7. وارد کردن  آدرس loopback با پورت 5001(127.0.0.1:5001)

## نکات تکمیلی

* برنامه قابلیت نصب از طریق chrome رو داره
* اگر در شبکه باشی سایرین با استفاده از ip کامپیوترت میتونن از  این سیستم استفاده کنن
* تمامی تنظیمات(مثلا پورت و ...) قابل تغییر هستن
